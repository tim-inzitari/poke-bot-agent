# Security policy

This is a research source release and is not a hosted service. Please report a
suspected credential exposure or exploitable issue privately to the repository
owner through GitHub's private vulnerability reporting feature. Do not include
live credentials, private replay data, or private infrastructure details in a
public issue.

Only the latest commit on `main` is supported. Downloaded Kaggle assets,
third-party engines, model files, and user-created deployment configurations are
outside this repository's security support boundary.
