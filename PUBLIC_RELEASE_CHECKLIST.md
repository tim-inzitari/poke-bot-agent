# Public release checklist

- [x] Fresh Git history; no private development objects copied.
- [x] Checkpoints, feature corpora, replay evidence, wheels, and native binaries excluded.
- [x] Competition-only engine source excluded.
- [x] No literal provider token or private-key block found in exported text.
- [x] Package metadata, license boundary, and third-party notice present.
- [ ] Run full secret scanning in the destination hosting platform.
- [ ] Enable branch protection and private vulnerability reporting.
- [ ] Confirm the destination repository visibility and description.
- [ ] Run native/GPU tests in an environment with independently obtained competition assets.
